# Local processing queue adapter

Explicit catalogue-asset requests for cleaning copies/video clips and image masks.
Reuse the existing Router and LocalExecutor. Source/CAS/edit/file gates, verified
private input snapshots and contained CPU subprocesses precede bounded adoption.
Migration 12 adds versioned processing derivations, independent output reviews and
retry receipts while preserving migrations 1–11. The derived service atomically
registers actual outputs as derived, never originals; all applicable independent
human reviews must pass before ordinary file access. Engineering stages do not
approve output quality, privacy, licensing or semantic labels.
HTTP installation is in `http.py`; `LocalConfig.processing` and the configured
executor dispatch are implemented in `api/config.py`, disabled by default.
