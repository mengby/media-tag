# D06 字段复核

`models.py`定义单字段决定、人工观察、整行确认与缺口操作；`policy.py`校验类型、契约选项及显式发布词表消费门槛。
`service.py`保存真实会话操作者、源哈希、证据和CAS修订；`schema.py`是迁移6，含CSV发布元数据。
词表发布属于D13；未提供正式发布时不从模板示例或省略项补造医学选项。字段确认不批准人脸输出、许可或剪辑用途。

`qualification.py`统一当前建议/逐字段最新范围、原人工值和拒绝记录的资格与元数据栅栏。
precision/local_topics 建议复用各自生产报告验证器；详情标明实际可用性和人工采用资格。
accept/reject 的字节验证在只读事务完成，写事务只重验元数据再保存人工决定。
