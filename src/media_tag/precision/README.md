# Replaceable precision adapters

Local, explicitly configured Python bridges with pinned code hashes. No model is
selected or downloaded by default. The runner is assigned to a Windows process
tree before bridge code loads; timeout/cancellation waits for the whole tree.
Images and full bounded video/animation/audio inputs preserve original bytes.
Only structured draft fields are accepted, never approvals or effective values.
Protocol tests are not evidence of real model capability or semantic accuracy.
