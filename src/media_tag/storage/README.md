# 文件存储边界

`FilesystemBackend`在配置根目录内读取文件，只有明确可写的对象后端可接收副本。以流计算SHA256，复制到同卷临时文件，校验后通过硬链接原子发布自有副本（不链接原件）；同哈希复用时重新校验。没有覆盖、删除或重命名源素材的方法。

对外按后端ID及相对对象key操作，不存物理根目录/凭证进数据库。只读原件后端与可写对象后端根目录必须分离。静态路径穿越、链接/重解析点和Windows设备路径拒绝；部署时根目录还须由受控服务账号管理。

`OssBackend`是明确未配置的接口占位，所有I/O报错；不回退本地原件。接口、事务边界与限制见 [D01说明](../../../docs/catalog-storage.md)。
