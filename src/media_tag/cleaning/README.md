# Explicit cleaning core

CT-07/CT-08 local file core. Originals remain read-only; generated copies use a
stable source/recipe name and full hash manifest. Video segments are really cut,
not annotations. Frame clocks, audio overlap and time maps are verified against
actual output. Image/animation/audio copies preserve their encoded originals.
No default 3–5 second truncation, global strategy approval, privacy approval,
medical confirmation or semantic labels are created here.
