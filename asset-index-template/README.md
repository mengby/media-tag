# 素材库索引飞书模板

- `feishu_asset_index_template.csv`：只有表头，导入飞书多维表格后作为素材索引表。
- `feishu_asset_index_fields.csv`：逐字段说明，含飞书字段类型、可选项、填写方式和一行示意。
- `feishu_gap_table_template.csv`：素材缺口表表头，记录找过但没找到的素材需求。
- `feishu_gap_table_fields.csv`：缺口表逐字段说明。用途、科室、器官选项与素材索引表共用；“补上的素材”导入后改为关联素材索引表。

CSV 导入后所有列默认是文本，需按字段说明把单选、多选、数字、日期、复选框、超链接、附件、人员列手动改类型并锁定选项。示例行的值未经核实，仅示意格式。

索引只描述素材内容与来源，不代表许可或医学审核通过；写入 `assets/` 的正式索引须在获授权的素材库维护任务中进行。
