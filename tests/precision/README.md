# Precision protocol integration tests

Isolated catalogues with the real template policy, CPU probe/evidence, real
Windows-contained bridge subprocesses and real synthetic media bytes. Bridges
normally return synthetic labels for protocol, evidence, queue and failure tests.
Set `MEDIA_TAG_TEST_LIVE_CODEX=1` to run `test_live_codex_image_through_worker`
with a signed-in Codex CLI. It sends a generated geometric image through the
ten-field pipeline, checks the visible color and shape, and verifies the report and draft status.
