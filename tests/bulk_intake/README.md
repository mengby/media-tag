# 本地批量入库验证

合成源目录、真实上传/素材库 ASGI 接口验证只读盘点、失败/排除、字节去重、身份绑定、中断续传与重跑不覆盖。
本地真实目录的运行清单和结果位于被忽略的 jobs/intake-*；不将原素材或模板复制进测试目录。


`validate_drafts.py` 为本机415张初稿/原35列导出的实际验证入口；baseline-only先保存人工/资产/任务基线，再执行完整验收。私有基线与表格不提交。

`validate_visual_fields.py`保存本轮人工/权限/原有成功阶段基线并验证真实415张画面字段、源/下载及模板导出；通过--progress只读查看状态。产物与数据忽略Git。
