# Similarity engine tests

Synthetic actual image/animation/video/audio bytes test descriptor stability,
audio gain/encoding behavior, bounded decoding, source binding and candidate
ordering. Separate isolated catalogues test current permissions, privacy gates,
version staleness and explicit relation decisions. No real-library duplicate
precision/recall, clinical labels, calibrated thresholds or automatic merge is
claimed by these checks.

`test_pipeline.py` and `test_config.py` exercise actual CPU queue/config intake,
unknown-type probe adoption, static GIF and animation/video/audio descriptors,
current-attempt repair, HTTP, and authorization. Oversized private report/source
copies are rejected before body reads, including the repair verifier.
