# D15工程验证

临时数据与合成图形检验授权/隐私门槛、字面/概念依据、否定/方向、显式人工关联、反馈生命周期、候选/试搜/发布隔离、受限CSV/XLSX预检及CAS。真实医学词表、医学准确性与独立业务样本不由这些测试证明。


`test_ai_drafts.py` 验证模型报告投影、失效/权限/显式视觉候选、35列导出、v10迁移及搜索不占写锁；`ai-drafts-browser.mjs`读取本地私有上下文，在真实浏览器检查初稿详情和开关，不发送外部图像。

`test_visual_fields.py`覆盖本地字段契约、人工值保护、原模板导出、统一批量/CLI、真实处理器像素预算、数值等价投影、微批隔离/缓存/降载/取消及真实浏览器→独立合成Worker→索引CSV全链路；后者不冒充真实VLM验收。

`visual-fields-browser.mjs`读取本地私有上下文，对真实运行实例只读验证四字段详情、初稿检索命中及批量入口可见；不点击扩大素材范围，不上传图像，截图保存在被忽略的结果目录。

`test_draft_search_speed.py`验证当前投影筛选与完整校验结果相同、篡改/撤权/取消/改版即时失效、缺失投影回退、只读事务视图隔离及视觉候选仍完整校验。`validate_search_speed.py`对真实本机实例和数据库副本做剖析、四类查询/公共API指纹对照、全部表和415份原件复验；实际数据/报告忽略Git，命令见 `docs/draft-search-performance.md`。
