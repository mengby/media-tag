# 跨接口工程演练

`validate_preview.py` 在本仓库新私有批次运行真实 API/MCP、固定字节任务内下载和完整合成预览。它不会修改或调用相邻剪辑仓库，也不声称真实 AI 宿主观看/业务用途验收或跨机器部署通过。当前用途检查单明确为合成契约夹具，真实D20/I01～I08签收仍须指定宿主、业务素材及部署机器。

`real_editing.py`、`bind_real_plan.mjs`、`publish_real_plan.mjs` 是随后用户指定 `20261107-demo` 的实际剪辑联调入口，见 [真实联调说明](../../docs/real-editing-integration.md)。它们会在明确选定的相邻项目新任务和 E:/asset 写入数据，并调用真实生产服务；不得作为普通单元测试自动执行。原生 Codex 图像审看须事先取得对应图片的发送许可，命令标志不能自行授予许可。`test_real_editing.py` 仅使用本地合成夹具验证拷贝边界与许可入口，无生产写入。
