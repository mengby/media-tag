# media-tag

供剪辑人员和 AI 剪辑共同使用的素材库：素材登记与后台打标、口语/专业词检索、独立人脸打码和视频变速、可追溯版本下载及表格导出。后续接入飞书并支持文件迁移到 OSS。

截至 **2026-11-07**，已完成需求与方案整理，已有常用术语候选表和交互草图；**功能开发、Windows 部署、API/MCP 接入及业务验收均未开始**。D00～D20 共21张任务卡，首期19张、后续/可选2张，已完成开发任务0张。
