## 启动与身份

在已有[D03本地配置](router-queue.md)中设置`"web_enabled": true`，默认关闭。需要变速时设置`retime.enabled=true`；人脸处理需`redaction.enabled=true`及D04绝对模型目录。模型后台分析由既有`models.enabled`控制，页面不让剪辑人员设置模型或点击“开始打标”。

```powershell
& .\.venv\Scripts\python.exe -m pip check
& .\.venv\Scripts\python.exe -m media_tag serve --config config/YOUR.local.json --port 8000
# 浏览器打开 http://127.0.0.1:8000/ui/
# 另一个终端按需执行已排队任务；此命令不是安装常驻服务。
& .\.venv\Scripts\python.exe -m media_tag work-once --config config/YOUR.local.json --worker-id YOUR_WORKER_ID
```

使用已有配置中显式绑定的editor/admin/reader凭证；没有默认用户或通用token。登录后原凭证输入立即清空，服务器发放随机HttpOnly、SameSite=Strict会话Cookie，最长8小时；HTTPS使用Secure，当前CLI仅loopback HTTP。服务重启使会话失效；退出会销毁会话并清空页面中的源帧、媒体、选择及上传表单。偏好存储只保存按人员区分的画廊/列表模式。

媒体由同源Cookie请求，支持浏览器原生video/audio/img及Range；不把凭证放进URL或JavaScript持久存储。不提供公共媒体静态目录。Cookie写操作要求同源Origin，跨站请求拒绝；CSP禁止外部脚本和内嵌页面，文件仍逐对象、哈希及来源链校验。生产TLS、受限账号、反向代理及常驻Worker留D07，当前未部署。

## 上传、入库、共享与后台分析

浏览器分块计算完整SHA256，内存按4MiB切片，不整文件载入内存；单文件上限沿用D09的2GB。上传分块大小采用服务器返回值，每块另验哈希。停止传输保留服务端已接收数据，可用上传ID重新选择原文件；续传先比对整文件哈希、大小及用途，再查询服务端offset。取消上传是独立操作。批量逐个上传，不修改本地原文件。

素材库上传按D09登记为本人私有库素材并自动安排分析；视频处理上传保持私有工作素材。生成成功只登记衍生版本，不自动进入库视图或共享；下载不会隐式入库。“加入素材库”使用明确确认、固定输出哈希、metadata revision和request_id，默认只有本人可见；可显式选择配置中的人员授予**此版本read**，不授权原件或兄弟版本。

SQLite追加迁移5：`library_entries`登记唯一asset成员关系/共享列表/本服务新增授权/后台job，`library_requests`做请求幂等，`library_events`记录操作者、输出哈希及共享范围。成员/授权/审计与素材revision在同一事务提交；无新表格字段或医学有效值。相同请求返回同一结果；重复入库不新增asset/variant/blob。移出库不删除文件，只撤回本入口创建的授权，不删除此前独立授予的权限。

入库事务先完整验证文件及隐私来源链，再登记待分析事件。服务端安排probe→evidence及已启用的OCR/face/CLIP；复用同素材既有library上传事件，启动时补派未记录job的条目。后台失败不撤销已获授权的文件，也不阻塞另一个处理任务；失败重试只重规划失败阶段及其依赖，保留成功前置。模型未启用时显示“技术就绪”，不声称已有AI标签；有模型时仍仅产生待审核建议。

CPU分析已支持经D17门槛校验的衍生输出；领取、心跳、结果采用和读取时均重查分析输入的隐私/生产者状态，撤回后不再采用后台结果。缩略图仅选取**当前版本SHA256**对应的已采用evidence；未准备好就返回不可用，不借用原件或父版本缩略图。

## 指定输出复核人

本地`redaction.reviewers`/`retime.reviewers`必须绑定实际editor/admin人员，默认空列表不能批准。输出所有者在处理页选择配置中的复核人，点击授权后只授予该输出的read权限并记录操作；不因此批准输出或入库。复核人在素材库勾选“待我复核”，查看当前输出的私有连续预览，人工核查后自行提交决定。

批准仍由D10/D11协议处理，绑定输出SHA256、recipe_hash、素材revision和指定复核人；不能继承父版本、其他配方或旧输出的批准。复核撤回后普通下载、缩略图和库中对其他人员的展示立即受阻；私有复核预览不充当批准下载。来源许可、医学确认及当前剪辑用途另行保留，页面不会声称完全匿名。

## 人员接口

仅`web_enabled=true`时安装。既有`/uploads`、`/redaction`、`/retime`、`/jobs`和`/v1/assets`接口复用同源会话，也继续支持原Bearer协议。

| 方法/路径 | 行为 |
| --- | --- |
| `GET /ui/` | 打包页面；只有页面外壳公开，不含数据或凭证 |
| `POST/GET/DELETE /ui/session` | 用已配置Bearer登录、会话/能力查询、退出 |
| `GET /ui/library?q=&mine=&workspace=&after=&limit=` | 按根组分页、逐版本授权；workspace包含本人工作素材，字面查询，不是D17语义检索接口 |
| `GET/POST /ui/library/{asset_id}` | 成员详情；`Enrollment`含request_id/expected_revision/output_sha256/recipients/active，只有owner可变更 |
| `GET /ui/tasks`；`POST /ui/tasks/{job_id}/retry` | 本人上传/任务；按expected_revision重试失败阶段 |
| `GET /ui/review-queue` | 最近100个有对象权限且指定人员可复核的pending/revoked输出，批准后移出待办 |
| `POST /ui/outputs/{asset_id}/assign-reviewer?kind=redaction或retime` | owner以expected_revision/output_sha256/subject_id显式授权已配置复核人 |
| `GET/HEAD /ui/media/{asset_id}?sha256=…` | 原生预览；download=true用普通文件门槛；review=redaction或retime仅私有复核预览，不能同时用download |
| `GET/HEAD /ui/thumbnail/{asset_id}?sha256=…` | 当前输出自己的PNG证据，暂无则404；隐私或授权失效则拒绝 |
| `GET /ui/scans/{job_id}/frames/{index}` | 扫描owner的真实源帧；重验当前扫描/租约/源权限及decoded_sha256，不向团队提供未打码帧 |
