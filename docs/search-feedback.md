# D15 检索、术语维护与反馈

2026-11-08。实现位于 `src/media_tag/search/`、`web/search.js`、`web/terms.js`。使用项目 `.venv`，不增加依赖；SQLite 迁移9保留旧迁移，可从8升级及回退。正式医学词表、代表性标注集和实际审核人员尚未提供，当前只验证工程协议与合成几何素材流程。

## 启用与使用

沿用 [人员页](personnel-ui.md)、[词表发布](terminology-release.md) 和 [文本模型](terminology-worker.md) 的私有本地配置、凭证和启动命令。增加以下配置后重启服务；依赖 `terminology.enabled`、`text.enabled`，模型可明确关闭以保留精确匹配。需要管理页及素材复核时还需 `web_enabled` 和 `review.enabled`。

```json
{"search":{"enabled":true,"max_assets":5000}}
```

素材库搜索框支持原话、发布术语和候选选择；可限定科室、器官、肯定/否定及变化方向。模型候选需明确选择，不默认勾选第一个。结果显示名称、人工字段、明确概念关联或可选 AI 初稿的命中理由。显式科室/器官筛选要求对应医学字段已确认，显式肯定/否定或方向筛选要求匹配的有效人工概念语境，名称/AI建议不能绕过。默认查询只使用当前授权且可下载的库内版本；工作素材仅在显式工作区查询中纳入。

“补充说法”保留搜索原话及可选原句，允许“不确定”。“对应不准确”分别记录被反馈的原版本映射和用户提出的目标；不会把错误映射自动当正确目标。用户可查看、补充或撤回自己的待处理记录。去重限定提交人、表达、目标、语境及版本；重复次数和每次来源保留，不把多义表达合并。已识别但无可见素材时可登记 D06 素材缺口，未知表达则引导补充对应关系；不暴露无权素材是否存在。

具有明确管理/发布能力的账号显示“术语词表”。支持候选列表、条目/状态筛选、来源查看、左右编辑与试搜、逐条勾选审核、发布差异、独立发布与查询状态、整组启用及回滚。停用概念/分类可指定替代条目。来源、适用条件、同义扩展开关均须明确填写；保存和试搜只作用于草稿。发布成功而索引构建失败时保留旧查询整组，管理页可重试启用；不能把“已发布”误认为已查询生效。

原始用途字段是 **用途大类**，只允许原契约8个选项；**过程/状态**是文本字段，可维护规范说法，仍要求逐字段医学复核。科室、器官/系统、疾病/症状沿用外部发布分类。没有增加、改名或改写六份原始模板及35/14列表头。

## 人工关联与边界

D06 标签复核页新增概念关联，绑定当前源 SHA256、实际观察记录、发布概念的语义摘要和医学字段依据。医学概念要求指定医学复核人，且其对应医学分类已在 D06 逐字段确认；未绑定可确认医学分类的概念拒绝关联。静帧不能确认动态方向；视频关联范围必须由本人连续观察区间覆盖。撤回保留审计。医学字段修订、概念含义变化或源字节变化使旧关联失效，整行索引确认需重新处理。

查询不生成医学标签、不发布词条、不批准许可或隐私；文件名扩展命中明确不是医学证据。默认不把“未标注肯定”解释为否定；否定和方向关联必须有实际人工语境依据。可选 AI 初稿只消费当前有效任务的已校验 OCR/术语报告，显示为未确认建议，不改人工值。处理副本的隐私门槛先于索引和报告扫描，未复核/已撤回版本不能经搜索回退到原件。

## 接口与分页

已可用接口由原有认证及同源会话保护，响应 `no-store`：

| 接口 | 行为 |
| --- | --- |
| `POST /search/query` | `request` 为 D14 ResolveInput；可给 selected_concept_ids、selection_lexicon_release_id、literal_only、include_drafts、mine、workspace、limit、cursor |
| `GET /search/vocabulary` | 当前查询整组的概念、分类及版本摘要 |
| `GET/POST /search/assets/{id}/concepts` | 查看/新增明确人工关联；`POST .../{link_id}/revoke` 撤回 |
| `GET/POST /search/feedback` | 本人提交与列表；详情、revision、decision 子接口分别支持查询、本人修订、管理决定 |
| `POST /search/gaps` | 人工登记画面需求，不伪造失败搜索日志 |
| `GET /search/management` | 明确管理/发布角色的候选、版本、状态和权限 |
| `GET .../candidates/{id}/diff` | 发布前问题与差异 |
| `POST .../candidates/{id}/trial` | 当前查询/草稿并列试搜，均受素材权限限制 |
| `POST /search/imports?format=csv\|xlsx` | 上传受限值表；详情检查及 preview 子接口执行映射预检/明确导入 |

按根素材聚合授权命中版本，每页最多50组。游标使用进程密钥签名，绑定账号、查询、语境、词表/索引版本与可见结果依据；数据、权限或版本变化返回409，伪造返回422，重启后应从第一页重查。搜索扫描当前授权元数据，默认预算5000版本，超预算明确503，不返回假完整结果。尚未经过正式容量与 P95 验收。

## 导入与 CSV

只接收 UTF8 CSV / XLSX 值表，明确选择工作表和列映射、预检后勾选行，导入到指定草稿。4MiB输入、128个ZIP条目、16MiB展开、1000数据行、50列、8K单元格上限。拒绝外部工作表、DTD/实体、路径逃逸、重复表头；公式/错误单元格逐行报告，不执行公式。原始导入副本和 SHA256 在忽略的 `jobs/import-*/` 中，只有上传管理人可读取。未知目标、缺来源或歧义可保留候选问题，不能自动发布。反馈转草稿最多附最近20条来源，完整提交历史另存事件表。

D06 导出新增显式 `include_confirmed_aliases`（默认关闭）。只给中文/英文检索词列追加至多8个已发布、明确同义且满足语境的别名；依据需为有效人工概念关联或已逐字段确认分类。相关、比喻、上下位、未确认 AI 建议不导出为同义词。保留人工值及未知/不适用状态、不写回数据库，公式转义沿用原逻辑。快照绑定词表及分类摘要，新词表启用后旧的同义词导出下载拒绝409；默认关闭的既有导出不受此项影响。
