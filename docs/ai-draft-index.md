# 本机模型结果与可检索 AI 初稿

2026-11-09。接续 [415张现有素材入库](local-intake.md)。本轮接通真实 OCR/人脸观察、CLIP 视觉向量、页面和公共检索；审核分配及 D16 正式评测仍后置。使用项目 `.venv`，原素材与剪辑端保持不动。

## 实际行为

- OCR 逐行原文和识别分数形成 `ocr_text` 初稿；它表示图中文字，不自动变成画面主体、疾病或同义词。
- 人脸报告形成抽样观察；有检测框时给出“有-需打码”候选。未检出仅记录“抽样帧未检出人脸”，不写“无”，不推断身份，也不批准打码输出。
- CLIP 已有的 512 维归一化图像向量进入索引。缺少已发布分类词表时，保留原任务 partial/unpublished_vocabulary；分类字段留空。向量可用于独立启用的视觉候选检索，不拿视觉相似度充当医学分类概率。
- 每条观察绑定源 SHA256、任务 ID/租约、模型和预处理版本、报告 SHA256、帧 SHA256及时间。文件名只作名称/旧原话查询，不作为上述标签的证据。
- 只采用当前未取消、活动任务的已释放结果。新一轮分析待执行/失败时，不回退该阶段旧成功结果；源、报告或帧不匹配时排除初稿。重复读取和批次生成复用同一观察 ID，不写人工有效值、审核记录或词表发布。

## 存储及自动更新

数据库增加第10次事务迁移 `ai_draft_documents`，原9次迁移和35/14列模板不变。每个素材、阶段最多一个当前投影；原模型报告仍是证据，投影可重建。

本机 Worker 每次释放任务后在短事务中更新该素材投影；详情读取及显式批次生成也可补齐。检索与导出构建使用只读 SQLite 快照，重验当前报告/帧，避免整个415张查询占用写锁。当前可见性、撤回、权限、技术筛选和隐私/生产者门槛继续生效；不自动给 Codex reader 分享素材。

升级前备份在受保护 `data/local/backups/ai-drafts-v9-before-upgrade/`，不提交 Git。备份工具同时校验 v9/v10，旧 v9 备份可恢复后正常迁移；未知版本、错误迁移摘要仍拒绝。

首次真实大批量查询暴露原搜索整段使用写事务的问题：空闲 Worker 等待写锁超时后，监督进程重载服务，查询连接中断。已将搜索改为只读快照、投影采用短事务，并增加实际并发写入测试；失败的首轮验收不算通过。

## 页面与接口

在本机素材库选中素材，详情显示“AI 标签初稿（未确认）”，含实际观察和模型/帧证据摘要。搜索默认勾选“包含未确认 AI 建议”；“视觉候选（未校准）”需独立勾选。关闭初稿开关后，模型观察不进入匹配。审核页面和审批门槛保留。

已可运行的接口（沿用现有 Bearer/本机会话和权限）：

```text
GET /search/assets/{asset_id}/ai-draft
POST /search/query
POST /v1/assets/search
```

详情不返回原路径、私有报告路径或原始向量。公共 API/MCP 查询请求增加可选 `include_visual_drafts`，保持 `include_drafts=false`、`include_visual_drafts=false` 的默认值；旧调用行为不变。

公共查询示例：

```json
{"query":"人体器官示意图","include_drafts":true,"include_visual_drafts":true,"use_model":false,"limit":10}
```

OCR/观察文字为原文匹配；视觉通道使用同版本 Chinese-CLIP 文本塔与现有图像向量做余弦排序，只返回至多10个候选，优先级低于文字及人工依据。不默认做未经校准的相似度阈值判断；相似度最高仍可能不适合实际用途。否定、动态方向、疑义或明确语境约束不由静态向量自动证明。

视觉文本编码使用本地权重、离线环境和隔离 CPU 子进程，45秒超时、单并发、1秒排队预算、128条进程内查询缓存。超过52 token等不可用情形明确降级，仍可查原文/OCR；不发外部 AI 请求，不占 Worker GPU 配额。没有新增依赖或自动下载模型。
