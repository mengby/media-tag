# 素材库实施计划

整理日期：2026-11-07。状态：D00～D04、D09及D10工程已验收，D17文件基础已实现、整项实施中，下一步可推进D11变速与D12处理页、D06复核与D13词表/语义前置；D07/M0环境准备继续，实现边界见 [D00说明](contracts.md)、[D01说明](catalog-storage.md)、[D02说明](media-evidence.md)、[D03说明](router-queue.md)、[D09说明](upload-variants.md)、[D17文件基础](file-access.md)。保留 D00～D20 共 21 张任务卡，不因重新整理而重编号。首期包含 19 张；D05 为可选增强、D08 为后续对接。完成状态仅在 [PROGRESS.md](PROGRESS.md) 维护。

## 实施原则

先固定契约和可运行的文件链路，再做真实处理和语义能力，最后进行跨项目集成。基础 API 随核心开发，不等到 MCP 阶段才设计权限与版本。页面可以提前用明确标识的模拟结果验证交互，但任务完成必须使用真实服务和要求的真实模型/媒体。

每个阶段均有可检查产物和出口，不把“开发完成”直接当“业务验收通过”。没有启动日期、人员投入和环境访问条件前，不承诺日历交付日；本计划按里程碑排依赖，M0 结束后再制定容量与时间基线。

## Router 与 Worker 下发办法

开发 Router/集成者负责冻结共享契约、选择已满足前提的卡、明确允许修改路径和基准提交、合并检查与状态更新。Worker 只负责本卡产物，不自行改另一个模块的 schema/依赖/主入口；必要公共变更提交给集成者。并行开发若启动，使用隔离分支/工作树，不能同时覆盖共享文件。

每次下发包含：任务 ID、关联 R/N、基准提交、AGENTS、卡片原文、输入版本、前置产物、可修改目录、非目标、A/T/I 用例和必须返回的证据。跨仓库 D19 单独明确范围，当前文档整理不算下发。

Worker 返回：变更与提交、真实执行命令及结果、产物/报告位置、版本和输入哈希、未解决缺陷、建议下一步。代码可运行但没有真实推理/内容复查时，只能进入对应的联调或待验收状态，不能写已完成。

## 阶段验收与交付物

验收详细用例只维护在 [A01～A11 总体验收](DESIGN_AND_IMPLEMENTATION.md)、[T01～T12 术语验收](TERMINOLOGY_MAPPING_PLAN.md) 和总体方案第 12 节 I01～I08 中，本计划只引用编号，避免多套数值漂移。

拟定数值包括明确解析准确率≥95%、明确常用表达覆盖率≥80%、素材 Hit@10≥90%，以及指定负载下搜索 P95≤2秒；需在独立验收前冻结。医学方向和权限类硬规则不能用平均分抵消。人脸输出完整复核、变速声画时间测量、原件哈希检查都要真实样本证据。

每个阶段应有：可复现启动方式、锁定依赖与模型版本、对应用例报告、样本清单/哈希、已知限制、部署/回退说明。真实数据与报告放忽略目录；仓库保存测试结构、合成夹具和操作文档。每个实际新增工作目录补 README，不为未来任务预建空目录。
