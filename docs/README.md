## 维护规则

用户指令和AGENTS约束始终适用。需求/范围查REQUIREMENTS，设计状态查ARCHITECTURE，当前实施顺序查IMPLEMENTATION_PLAN，真实进度只在PROGRESS更新。专题记录详细实现和验收，旧阶段编号P0～P5仅作为专题交付分组，不再代表当前时间顺序。

变更需求时同步关联任务和验收；变更公共契约由集成者记录影响；完成任务必须更新进度和证据。遇到冲突同步修正涉及文档，不能依赖“读者自行理解哪个更新”。不把已产出文档、已运行模拟器与真实功能通过验收混为一谈。

原始规则与表头由本地 ../asset-index-template/ 保存，保持Git忽略。运营词表、媒体、数据库、报告及导出表格不复制到文档目录提交。新增文档在本索引登记，不为占位建立空目录。
