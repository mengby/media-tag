# 素材库需求基线

整理日期：2026-11-07。基线版本：v0.1。业务范围依据当前用户需求收口；技术选择及数值验收目标仍按待定项管理，本次整理不表示已经授权部署或启动所有开发任务。

## 项目目标与使用者

建立一个供剪辑人员和 AI 剪辑共同使用的素材库：上传并登记素材，后台生成标签建议，通过口语或专业术语检索，取得可追溯的文件版本；独立提供人脸打码和视频变速，处理结果可扩充素材库；导出既有表格，后续接入飞书并支持文件迁往 OSS。

| 使用者 | 需要完成的工作 | 边界 |
| --- | --- | --- |
| 剪辑人员 | 上传、搜索、预览、下载、打码/变速、补充说法 | 不要求手动启动打标或填写完整表头；不默认拥有审核权限 |
| 素材与词表管理人 | 修订标签、审核术语对应、管理来源、发布索引/词表、导出 | 人选待指定；词表审核与素材医学审核权限分开 |
| AI 剪辑项目 | 按镜头需求检索、查看画面、取得固定版本并登记到任务 | 不写正式标签、不发布词表，不以标签命中代替当前用途检查 |
| 服务运维者 | 部署、备份、恢复、账号、存储迁移与故障处理 | 角色职责拟定，不虚构现有人员或账号 |
